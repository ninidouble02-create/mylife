# My Life OS PWA v0.4

本版目标：从“入口能点”升级为“核心模块可以真正日常使用”。

已实现：
- Today：Routine、今日计划、Habit 直接打卡、Mood 确认保存、纪念日提醒
- Plan：完整月视图、日期选择、起止日期、编辑/删除、Plan Pool、纪念日
- Routine：时间、重复规则、自定义星期、步骤、编辑/删除
- Habit：固定/次数/弹性，日/周/月周期、目标次数、弹性间隔、总结、编辑/删除
- Life：照片、地点、标签、日期时间、照片墙、编辑/删除
- Drinks：照片、品牌、名称、评分、价格、备注、饮品照片墙、可同步 Money
- Money：账单、小票照片、自定义分类、月预算、编辑/删除
- Health：体重、生理期、运动、睡眠、步数、体重趋势
- Knowledge：笔记、标签、搜索、编辑/删除
- Focus：番茄/倒计时/正计时，悬浮计时
- Archive：月度 Life/Money/Focus/Habit 摘要、照片、Mood、月记
- Search / 本地备份

数据仍为 Local First。照片存 IndexedDB，结构化数据存 localStorage。
